# Spring Boot Learning Repository

This repository contains all the Spring Boot projects I built while learning Spring Boot.

## Learning Path

Follow the projects in this order:

1. myfirstapp
   - Spring Boot basics
   - Spring Initializr
   - Running a Spring Boot application

2. spring-demo-one
   - Dependency Injection
   - @Component
   - @Autowired
   - Constructor Injection
   - Setter Injection
   - @Qualifier
   - @Primary

3. spring-demo-two
   - Bean scopes
   - Bean lifecycle
   - @PostConstruct
   - @PreDestroy

4. spring-rest-crud
   - REST APIs
   - @RestController
   - CRUD operations
   - HTTP methods

5. spring-data-jpa
   - JPA
   - Hibernate
   - Entity mapping
   - Repository pattern

6. spring-security
   - Authentication
   - Authorization
   - Spring Security basics

## Technologies

- Java 21
- Spring Boot
- Maven
- Spring Core
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL

Based on Chad Darby's Spring Boot course.

Each project focuses on a specific topic and builds upon the previous one.
